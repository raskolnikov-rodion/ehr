# dashboard

Feature library for the dashboard page. Import alias: `@ehr/dashboard`.

Lazy-loaded at `/dashboard` and protected by `authGuard`. The page composes shared `CardComponent` widgets from `@ehr/ui`.

## Public API

| Export          | Description                         |
| --------------- | ----------------------------------- |
| `PageComponent` | Standalone dashboard page component |

## Running unit tests

```bash
npx nx test dashboard
```
